Number Guessing Game

A simple and interactive Number Guessing Game built with Python. The program generates a random number, and the player must guess it with the help of hints until the correct number is found.

 About the Project

This project was developed to practice core Python programming concepts, including:

Variables
User Input
Conditional Statements (if, elif, else)
Loops (while)
Random Number Generation
Problem-Solving and Logical Thinking
 Features
 Generates a random number between 1 and 100
 Provides hints if the guess is too high or too low
 Tracks the total number of attempts
 Displays a congratulatory message when the correct number is guessed
 Beginner-friendly and easy to understand
 Technologies Used
Python 3
random module

 How to Run
Clone the repository:
git clone https://github.com/your-username/Number-Guessing-Game.git
Navigate to the project folder:
cd Number-Guessing-Game
Run the program:
python number_guessing_game.py
